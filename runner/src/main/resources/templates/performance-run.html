Hoe kiest de app vergelijkbare runs?

Altijd vereist (anders valt een run af): zelfde soort training, allebei buiten of allebei op de loopband, afstand tussen 0,8 en 1,25 keer deze run, zelfde terreinklasse, en allebei met of allebei zonder hartslag.

Extra overeenkomsten (de vinkjes): bepalen alleen de volgorde. Bij een gelijk aantal vinkjes komt de run die het dichtst in de tijd ligt eerst. Er is geen gelijkenisscore.
